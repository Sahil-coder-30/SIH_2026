## 🌐 Overview

This repository contains a curated, battle-tested library of **14 production-grade AI Agent Skills**. Each skill encapsulates domain-specific architectural blueprints, CLI tooling, automated validation scripts, design systems, and step-by-step checklists.

By linking these skills into your coding agent (**Antigravity**, **Claude Code**, **Cursor**, **Windsurf**, **GitHub Copilot**), you eliminate hallucinated code patterns, outdated framework syntax, fragile payment/rate-limiting logic, inconsistent microservice documentation, and generic UI outputs.

> [!TIP]
> **What makes a Skill "Production-Grade"?** Every skill includes strict **Hard Architectural Rules**, zero-dependency validator scripts, and Human-in-the-Loop (HITL) checkpoints to ensure code generated by AI is deploy-ready on day one.

## 💡 How Coding Agents Use Skills

Each skill folder contains a standardized `SKILL.md` file formatted with YAML frontmatter:

- 🎯 **Automatic Activation**: Agents continuously evaluate prompt intent against the skill's `description` and activation rules.
- 📚 **Hierarchical Deep-Dives**: Skills bundle detailed playbooks (`references/`), zero-dependency CLI scripts (`scripts/`), and production templates (`assets/`).
- 🛑 **Strict Architectural Rules**: Prevents AI anti-patterns (e.g. client-side payment verification, static rate-limiting timers, uncleaned GSAP listeners, or inconsistent microservice contracts).
- 🔄 **Automated Verification Loop**: Ships with CLI validators (`validate_readme.js`, `prd_benchmark.py`, `audit.mjs`, `validate-tokens.cjs`) so the agent verifies its own work before presenting it.

### 1. ⚡ AI Rate Limiter & Token Bucket (`ai-rate-limiter`)

Engineered for AI/LLM SaaS applications to manage API token budgets, prevent context exhaustion, and execute model fallbacks under heavy load.

- **Key Features**:
  - **Redis Token Bucket**: Sub-second continuous refill algorithm powered by atomic Redis Lua scripts.
  - **Dynamic Token Burning**: Deducts tokens dynamically based on input context length rather than static request counts.
  - **Graceful Pro Tier Degradation**: Automatically falls back from flagship models (`claude-3-5-sonnet`) to high-speed, lower-cost models (`claude-3-5-haiku`) when bucket drops to zero.
  - **Prompt Cache Deductions**: Integrates Anthropic & OpenAI prompt caching headers to calculate up to 90% savings on context reads.
- **Workflow**:
  1. Load atomic Lua script (`references/redis-token-bucket-lua.md`).
  2. Estimate prompt context size before calling LLM APIs.
  3. Execute `consumeTokenBucket`. Fail open or degrade model tier dynamically.
  4. Deduct cached tokens post-call using `cache_read_input_tokens`.

### 8. 💫 GSAP Scroll Animations for React (`gsap-scroll-animations`)

Production patterns for fluid scroll-driven animations in React using `gsap` and `ScrollTrigger`.

- **Key Motion Patterns**:
  - 📌 **Pin & Curtain Reveal**: Sticky hero container with content sliding over gracefully.
  - ⏱️ **Scrub-Linked Timeline**: Progress tied directly to user scroll delta.
  - 🃏 **Stagger Reveal**: Sequential fade/slide animations for grids and feature cards.
  - 🌌 **Parallax Layers**: Multi-depth speed offset across background visual elements.
  - ↔️ **Horizontal Scroll Section**: Sideways scrolling galleries within vertical page flow.
- **Hard Rules**:
  - Always scope GSAP setups inside `useLayoutEffect` with `gsap.context()` and `ctx.revert()` cleanup to eliminate React 18 strict mode double-triggers.
  - Animate GPU-accelerated properties (`transform`, `opacity`) exclusively.

## ⚙️ Installation & Setup

### 1. System Requirements

- **Node.js**: v18.0.0+
- **Python**: v3.10+ (macOS/Linux: `python3`, Windows: `python`)

### 2. Environment Variables

Create a `.env` file in your workspace root or export environment variables:

```bash
export GEMINI_API_KEY="your-gemini-api-key"   # Required for Logo/CIP/Banner AI visual generation
export REDIS_URL="redis://localhost:6379"     # Required for AI Rate Limiter & Payment Idempotency
export RAZORPAY_KEY_ID="rzp_live_xxx"          # Required for Payment Integration
export RAZORPAY_KEY_SECRET="secret_xxx"
```

### 3. Registering Skills with AI Agents

Place or link skill directories according to your coding agent:

- **Workspace Scope (Antigravity / Cursor / Claude)**:
  Copy skill folders to `.agents/skills/<skill-name>/` in your repository root.
- **Global Agent Scope**:
  Copy skill folders to `~/.gemini/config/plugins/` or `~/.claude/skills/`.

## 🎯 Best Practices for AI Agent Prompting

To ensure your AI coding agent produces optimal, production-grade output:

> [!IMPORTANT]
> 1. **Use Exact Trigger Keywords**: Mention specific skill names in your request (e.g. *"Use `microservice-readme-architect` to document our auth service"* or *"Use `ui-ux-pro-max` for a dark mode dashboard"*).
> 2. **Require Codebase Grounding**: Instruct the agent to inspect existing routes, schemas, and dependencies before drafting code or docs.
> 3. **Enforce Hard Architectural Rules**: Remind agents that non-negotiable rules in `SKILL.md` must be obeyed strictly.
> 4. **Run Validator Scripts**: Always execute the bundled validator script (`validate_readme.js`, `prd_benchmark.py`, `audit.mjs`, `validate-tokens.cjs`) after code/doc generation to verify quality automatically.
